# ml-labworks

Лабораторные работы по дисциплине «Машинное обучение».

|  |  |
|---|---|
| Дисциплина | Машинное обучение |
| Студент | Масенькин Максим |
| Группа | ПИбд-41 |
| Вариант | 20 |

Каждая работа — отдельный ноутбук в [`notebooks/`](notebooks/). У каждой работы своя ветка
`labwork-0N`, влитая в `master` через pull request. Выводы ячеек хранятся в репозитории, поэтому
графики, таблицы и примеры текста видны без перезапуска.

## Данные

Основной набор данных — сделки инсайдеров Tesla
([Tesla Insider Trading](https://www.kaggle.com/datasets/ilyaryabov/tesla-insider-trading) на
Kaggle): 156 сделок с 10.11.2021 по 28.12.2022, 9 столбцов. Он используется во всех работах, где
задание требует своих данных: ЛР 3 (часть 2) и ЛР 4–6.

Таблица 1 методички закрепляет за вариантом 20 набор «Он-лайн обучение», однако в курсе «Методы
искусственного интеллекта» работа велась с набором Tesla, а ЛР 3 (часть 2) прямо продолжает
задачу из того курса. Поэтому данные взяты оттуда, а модели, алгоритмы и их параметры — по
варианту 20.

Первая часть ЛР 3 использует набор [Титаник](https://www.kaggle.com/datasets/heptapod/titanic).

Тексты ЛР 7 находятся в общественном достоянии:

- «Капитанская дочка» и пять «Повестей Белкина» А. С. Пушкина — из
  [Викитеки](https://ru.wikisource.org/), в современной орфографии;
- английский перевод тех же произведений Т. Кина 1916 года — из
  [Project Gutenberg](https://www.gutenberg.org/ebooks/55219).

Напарника с нечётным вариантом, у которого текст английский, нет, поэтому его часть работы
эмулирована на переводе.

Все наборы скачиваются в `data/` при первом обращении и дальше берутся оттуда. В git они не
хранятся. Скачать всё сразу можно командой `just data`.

## Запуск

Нужны [uv](https://docs.astral.sh/uv/) и [just](https://just.systems/).

```sh
just sync      # зависимости по uv.lock
just data      # скачать наборы данных (необязательно, ноутбуки скачают их сами)
just lab       # JupyterLab в notebooks/
```

ЛР 7 требует Keras и TensorFlow. Они вынесены в отдельную группу зависимостей, чтобы остальные
работы не тянули около 6 ГБ:

```sh
just sync-dl
```

На Linux TensorFlow ставится вместе с библиотеками CUDA, и ноутбук рассчитан на видеокарту NVIDIA.
Он обучает 9 сетей заново при каждом запуске, на RTX 4080 это около 47 минут. Веса не сохраняются,
но результаты совпадают между запусками до третьего знака.

## Разработка

```sh
just hooks          # git-хуки
just lint           # ruff check, ruff format --check, mypy
just fix            # автоисправления ruff
just run-lab 01     # выполнить ноутбук сверху вниз; для ЛР 3 — 03_1 и 03_2
just run-all        # выполнить все ноутбуки, для ЛР 7 нужен just sync-dl
just --list         # все рецепты
```

Общий код работ лежит в пакете [`src/mllab`](src/mllab/): загрузка данных, предобработка,
метрики, графики и таблицы, а для ЛР 7 — подготовка текста и генерация. Линтеры настроены в
`.ruff.toml` (включая ноутбуки) и `.mypy.ini` (только `src/mllab`).
