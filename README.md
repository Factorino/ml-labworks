# ml-labworks

Лабораторные работы по дисциплине «Машинное обучение».

**Автор:** Масенькин Максим, группа ПИбд-41
**Вариант:** 20

Каждая работа — отдельный ноутбук в [`notebooks/`](notebooks/) и отдельная ветка,
влитая в `master`.

## Данные

Основной набор данных — **Tesla Insider Trading**
([kaggle](https://www.kaggle.com/datasets/ilyaryabov/tesla-insider-trading)): 156 сделок
инсайдеров Tesla за период с 10.11.2021 по 28.12.2022, 9 признаков.

Таблица 1 методички закрепляет за вариантом 20 набор «Он-лайн обучение», однако в курсе
«Методы искусственного интеллекта» работа велась с набором Tesla, а ЛР 3 (часть 2) курса
«Машинное обучение» прямо продолжает задачу из того курса. Поэтому данные взяты оттуда,
а модели, алгоритмы и их параметры — по варианту 20.

| Столбец   | Содержание                                                                             |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| `insider`      | ФИО инсайдера, 7 значений                                                    |
| `relationship` | должность, 5 значений                                                           |
| `date`         | дата сделки                                                                            |
| `transaction`  | тип сделки:`Sale` (99) или `Option Exercise` (57)                                |
| `cost`         | цена за акцию; ноль в 18 строках — исполнение опционов |
| `shares`       | количество акций в сделке                                                  |
| `value`        | сумма сделки в долларах                                                      |
| `shares_total` | акций во владении после сделки                                         |
| `sec_form_4`   | отметка о подаче формы SEC Form 4                                             |

ЛР 3 (часть 1) дополнительно использует набор
[Титаник](https://www.kaggle.com/datasets/heptapod/titanic).

Оба набора скачиваются и кэшируются в `data/` при первом обращении.

## Запуск

Требуются [uv](https://docs.astral.sh/uv/) и [just](https://just.systems/).

```sh
just sync      # зависимости по uv.lock
just hooks     # git-хуки (опционально)
just lab       # JupyterLab в notebooks/
```

ЛР 7 требует Keras и TensorFlow — они вынесены в отдельную группу зависимостей, чтобы
остальные работы не тянули ~600 МБ:

```sh
just sync-dl
```

## Разработка

```sh
just lint          # ruff check, ruff format --check, mypy
just fix           # автоисправления ruff
just run-lab 01    # выполнить ноутбук сверху вниз
just run-all       # выполнить все ноутбуки
just --list        # все рецепты
```

Линтеры настроены в `.ruff.toml` (включая ноутбуки) и `.mypy.ini` (только `src/mllab`).
Выводы ячеек ноутбуков коммитятся сознательно: графики и метрики — это и есть результат
работы, он должен читаться в репозитории без перезапуска.
